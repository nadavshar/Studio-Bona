Bona Calendar Sync

An internal calendar automation for Studio Bona (Tel Aviv)

What it does

Studio Bona is a dance and movement space in Tel Aviv. Staff manage bookings in a private Google Calendar. Bona Calendar Sync reads that calendar and writes a sanitized version — only which time slots are busy or free, and which room — to a separate public calendar, which powers the live availability widget on the studio's public website, studio-bona.com.

Data access
  • Read-only access to Studio Bona's own internal booking calendar (Google Calendar API, calendar.readonly scope).
  • Write access to a separate, purpose-built public calendar that the same business owns (calendar scope), used only to publish sanitized availability.
  • No other Google service is accessed — no Gmail, no Drive, no Contacts.
  • No data from studio visitors or website users is collected by this app.

Full details: Privacy Policy.

Who uses it

This is a single-business internal tool, connected only to Studio Bona's own Google account. It is not distributed, not installable by third parties, and has no other users.
